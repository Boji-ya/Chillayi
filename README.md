# Chillayi 嘉義旅遊 App

## 專案簡介
Chillayi 是一款以嘉義旅遊資訊為主的行動應用程式，
整合景點、餐飲、住宿、交通及活動等資訊，
提供使用者更方便、直覺的旅遊資訊查詢，而不需要頻繁切換各類型app

## 主要功能

- 景點、餐飲、住宿資訊查詢
- 嘉義地圖與地點瀏覽
- 大眾運輸動態
- 活動資訊
- 使用者收藏功能
- 社群交流功能
- AI 旅遊問答

## 使用技術

- Flutter / Dart
- Firebase / Firestore
- Google Maps
- AI / LLM
- REST API

## 專案特色

透過 Flutter 建立跨平台行動應用程式，
並結合 Firebase 進行資料管理與使用者功能，
同時整合 AI 功能，提供旅遊相關的智慧問答服務。

## 開發環境

- Flutter
- Dart
- Firebase
- Android Studio
